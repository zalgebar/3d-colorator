Tick pieces, then New group (2+) to link them, or Add to group to drop just the ticked pieces into an existing one — no need to re-tick current members. A group shares one color across every member; Collapsed shows it as one row for visitors, Separate keeps the parts listed but color-locked. Data-wise a group is { id, label, members[], collapsed, color } and members keep their own transform & visibility.
