STL duplication: clone a piece so one STL file appears as several independent instances in the build — each with its own name, position and color. A duplicate is simply another piece pointing at the same file; instances of one STL are detected and badged automatically. Drag the blocks to place each instance.

Pieces

Each row is one instance. ⧉ duplicates once; the layers icon opens Duplicate & Link; trash removes an instance — except the last copy of an STL.

Instances of one STL share the file but nothing else — separate color, transform and name. The layers button makes several at once and can link them so they always match color. You can't delete the last instance of an STL — if a Print doesn't need a part, drop that STL from the Print/repo instead. Data-wise duplicating just appends { id, label, file:same, position:offset, color, palette }.

Try it: on Buttons, click the layers icon → make 3 copies with Link checked. All four share one color (recolor any one — they all change) and carry a teal linked badge. Or use plain ⧉ for independent copies. Drag each block to place it, rename inline, and delete extras — the last instance of an STL can't be deleted.
